git checkout -b branch-name — create and switch to a new branch
git push -u origin branch-name — push a new branch to GitHub
git checkout main — switch back to main
git pull — sync local main with GitHub
git merge branch-name — merge a branch into your current branch
git log --oneline — see recent commit history in compact form
git status — see which files are changed or staged
git checkout branch-name — switch to an existing branch (no -b)


feature/ — adding new functionality
fix/ — fixing a bug
hotfix/ — urgent production fix
chore/ — cleanup, refactoring, no logic changes
